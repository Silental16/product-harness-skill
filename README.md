# Продуктовый харнесс — скилл для Claude Code и Codex

Скилл берёт идею продукта, модуля или фичи и за семь шагов отвечает, что строить, стоит ли строить X или сколько X даст: формула запроса твоими словами, кто уже это делает, сегменты, решения, деньги и отсев, самая дешёвая проверка с порогом и карта возможностей с ответом «глубже», «убить» или «не знаем». Агенты собирают факты из открытых источников и снимают каждую страницу, а скрипт сверяет каждую цитату со снимком. Прогон ждёт твоего ответа дважды — после формулы и в конце: решаешь ты.

## Установка

```bash
npx skills add Silental16/product-harness-skill --skill product-harness -g -a claude-code codex -y
```

Вход в GitHub не нужен: репозиторий открытый. Нужны Node.js и git. Команда кладёт скилл в `~/.agents/skills/product-harness` — эту папку читает Codex — и ставит на неё ссылку `~/.claude/skills/product-harness` для Claude Code.

Пакеты Python для снимков и сверки цитат: `python3 -m pip install --user pyyaml beautifulsoup4`. Pip пишет `externally-managed-environment` — та же команда с `--break-system-packages`. Python с python.org и отправка на стенд падает с `CERTIFICATE_VERIFY_FAILED` — запусти «Install Certificates.command» из папки Python в «Программах».

## Как начать

Открой сессию в пустой папке: там появится папка прогона `runs/<дата>-<тема>-<имя>/`. Git не нужен.

- Claude Code: `claude` в этой папке.
- Codex: запускай скриптом — он включает поиск и сеть, без них не работают снимки страниц и отправка на стенд:

  ```bash
  bash ~/.agents/skills/product-harness/tools/codex-run.sh
  ```

  Codex пишет, что модель недоступна для аккаунта, — добавь `-m gpt-6-sol`.

Первое сообщение — подставь имя и вход:

```text
Прогони идею по скиллу product-harness. Прогон веду я, <имя>.

Вход:
<идея, цель автора, ограничения — любым текстом или путь к файлу>
```

Первой строкой сессия даёт ссылку на страницу прогона на стенде команды и обновляет страницу после каждого шага. Страница открывается по ссылке без пароля, а список всех прогонов (https://product-harness-stand.vercel.app) закрыт паролем команды. Отвечаешь в чате сессии, а не на странице. Прогон уходит на стенд — не клади во вход секреты; не хочешь отправлять — скажи сессии не слать прогон на стенд, и она соберёт локальную страницу `ui.html`.
