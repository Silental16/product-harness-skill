# Снимок, строка цитаты, числа

Этот файл читают сборщики шага 2 и агент шагов 3–7. Выполняй его точно: по строке цитаты скрипт сверки находит цитату в снимке страницы, и любой вывод можно проверить без интернета.

`$SKILL` в командах ниже — путь из строки «SKILL=…» твоего сообщения. Подставляй его целиком: переменной `SKILL` в shell нет.

## Снимок

Каждую страницу, на которую ссылаешься, сохрани до того, как цитировать:

```bash
python3 $SKILL/tools/snap.py fetch --run RUN --url '<URL>' --title '<заголовок страницы>' --agent <имя> [--published ГГГГ-ММ-ДД]
```

Скрипт печатает номер снимка `src-NNN`. Дату публикации ставь через `--published`, если она есть на странице.

`fail: …` значит, что страница не открылась через curl. Тогда открой её своим инструментом и сохрани **весь видимый текст страницы** в порядке страницы, без выборки, со всеми отзывами и комментариями, которые видишь:

```bash
python3 $SKILL/tools/snap.py save --run RUN --url '<URL>' --title '<заголовок>' --agent <имя> --from-file <файл с текстом>
```

Такой снимок помечен как выписка модели. Прочитал только часть страницы — допиши в `--title` слова «часть страницы».

Файл с текстом клади во временную папку сессии (в Claude Code — её scratchpad, иначе `/tmp`) как `<имя агента>-<N>.txt`, не в папку прогона. Если `fetch` отработал, но в снимке нет нужного текста (страница собирается скриптом, снимок — пустая оболочка), сохрани страницу через `save` так же.

Форум на Discourse отдаёт curl пустую оболочку. Сними тему по адресу `<форум>/raw/<номер темы>`: там текст всех сообщений с датами. В строке цитаты ссылка — на этот адрес, в названии — «(raw)». Копию чужого сайта (зеркало Reddit, архив) бери, только если сам сайт не открылся. В `--title` допиши «копия <домен>», а сам оригинал назови в строке «Счёт» среди сайтов, которые не открылись.

Перед тем как записать цитату, проверь её:

```bash
python3 $SKILL/tools/snap.py find --run RUN src-NNN '<цитата>'
```

Аргументы бери в одинарные кавычки: в двойных shell превращает `$20` в `0`, и цитата не находится. Апостроф внутри одинарных кавычек пиши как `'\''`.

Код 0 — цитата нашлась. Код 1 — её нет в снимке: не пиши её.

## Строка цитаты

Одна строка, ровно в таком виде:

```
«<цитата дословно, на языке страницы>» — [<название страницы>](<URL>), <ДД.ММ.ГГГГ | без даты>, src-NNN
```

- Цитата — дословный кусок текста снимка до 40 слов, без сокращений и многоточий внутри.
- Кавычки внутри цитаты — „ “, а не « ».
- Дата — дата публикации, если она есть на странице; иначе «без даты».
- Цитата без `src-NNN` считается несверенной, и скрипт её зачеркнёт.
- Зачёркнутую цитату (`~~«…»~~`) не используй и не восстанавливай. Исключение — строка с пометкой «ошибка формата» в `card.md`: перепиши её по разделу «Правка по сверке».
- `src-NNN` стоит только в конце строки цитаты: не в таблице, не в расчёте, не в скобках. Строку, где `src-NNN` стоит вне этого формата, скрипт сверки зачеркнёт целиком. Нужен источник для числа или счёта — поставь рядом отдельную строку цитаты.
- Квадратные скобки в названии страницы замени на круглые: `[Feature request]` → `(Feature request)`.

## Правка по сверке

Запусти `python3 $SKILL/tools/check_quotes.py --run RUN` и исправь свой файл по разделу «Сверка цитат» в `check.md`: зачёркнутую цитату убери вместе с выводом, который на ней держался; строку с пометкой «ошибка формата» или «неточно» перепиши точным текстом снимка, проверенным через `snap.py find`, и сними с неё `~~` — или убери. Запусти проверку ещё раз.

## Числа

У каждого числа из сети есть строка цитаты, в которой это число стоит. Своё число — с пометкой «оценка» и расчётом рядом: «оценка: 12 000 клиентов × $240 в год = $2,9 млн». Число из формулы — с пометкой «из формулы».
