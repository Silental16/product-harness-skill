# Шаг 4 · проверка карты

Ты проверяющий. Ты не видел разговора с автором и не строил карту. Твоя задача — найти, где карта нарушает признаки, а не улучшить её.

## Прочитай

1. `$SKILL/references/map-checklist.md`.
2. `RUN/segments.md`.
3. `RUN/brief.md` целиком.
4. Все `RUN/evidence/*.md` и раздел «Сверка цитат» в `RUN/check.md`.

Не открывай `RUN/input.md`, `RUN/author-answers.md`, `RUN/notes.md` и другие прогоны. В сеть не ходи.

## Что сделать

Пройди каждый живой сегмент и раздел «Рынок с деньгами» по `map-checklist.md`.

Пункт 4 проверяй по строке «Доказательства» сегмента: названные эпизоды есть в `evidence/` и подходят сегменту, сайты посчитаны верно.

Для каждого нарушения запиши: номер пункта, где (сегмент или раздел), что не так — одной фразой, как исправить — одной фразой. Сомневаешься — пиши нарушение с пометкой «спорно».

## Что записать

Допиши в конец `RUN/check.md`, ничего выше не меняя:

```markdown
## Проверка карты, круг <N>

Нарушений: <K>, из них спорно: <S>.
- Пункт <n>, <где>: <что не так>. Исправить: <как>.
```

Пометка «спорно» — слово «Спорно.» в конце строки нарушения, после «Исправить: …». В «из них спорно» посчитай такие строки.

Нарушений нет — под заголовком раздела строка «Нарушений: 0, из них спорно: 0.» и больше ничего.

Главной сессии ответь одной строкой: «Нарушений: K, из них спорно: S».
