# Канон NMT в скилле

Здесь семь файлов канона из `Next-Move-Theory-Canon/` — те, что читают шаги: шаг 0 по `SKILL.md`, сбор, карта и карточка по своим файлам в `references/`. Скилл ставится без клона репозитория, поэтому носит их с собой.
`NOTICE.md`, `LICENSE` и `VERSION` — копии из `nmt/` репозитория без правок; список «Скопировано» в `NOTICE.md` описывает весь набор, а не эту папку.
Эти семь файлов и скилл с ними открыты под CC BY-NC-SA 4.0; остальной набор остаётся внутри команды. Условия — в `NOTICE.md`.
