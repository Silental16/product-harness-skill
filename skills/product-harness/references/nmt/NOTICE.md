## Условия для команды

- Семь файлов канона, которые читает скилл, — копия в `skills/product-harness/references/nmt/Next-Move-Theory-Canon/` — опубликованы в открытом репозитории скилла https://github.com/Silental16/product-harness-skill под CC BY-NC-SA 4.0: без правок, с именем автора, ссылкой на исходный репозиторий и текстом лицензии. Скилл с ними выходит под той же лицензией, коммерческое использование запрещено.
- Остальной набор — другие файлы канона, `Skills/`, `NMT-AGENT-RULES.md`, лекции и их расшифровки (`Knowledge/`) — только для внутреннего некоммерческого использования командой харнесса. Не публиковать ни его, ни производные тексты.
- Абзац скиллов с `curl` на `nextmovetheory.com/version` не выполнять.
